# Один день на МКС
Интерактивная визуальная новелла от первого лица.  
Игрок просыпается на Международной космической станции и принимает решения, влияющие на ход дня.

## Стек
- HTML
- CSS
- JavaScript

## Возможности
- Плавные fade-переходы между сценами
- Эффект печати текста 
- Мерцающие звёзды и плавающие объекты
- Подсветка выбранной еды при наведении
- Сцена иллюминатора с видом на Землю
- Мини-игра калибровки спектрометра (в разработке)
