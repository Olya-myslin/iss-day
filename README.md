# Один день на МКС
Интерактивная визуальная новелла от первого лица.  
Игрок просыпается на Международной космической станции и принимает решения, влияющие на ход дня.

## Стек
- HTML
- CSS
- JavaScript

## Демо
https://olya-myslin.github.io/iss-day/

## Уже реализовано
- Плавные fade-переходы между сценами
- Эффект печати текста 
- Мерцающие звёзды и плавающие объекты
- Подсветка выбранной еды при наведении
- Сцена иллюминатора с видом на Землю
- Мини-игра калибровки спектрометра
- Система накопления очков готовности игрока

## Планируется
- Логика одобрения или отказа выхода в открытый космос 
- Сюжетная ветка с выходом в космос 
- Альтернативная ветка с удалённой починкой станции 
- Несколько концовок, зависящих от выборов игрока 
- Секретная сцена после выхода в космос 
- Цифровой дневник космонавта с эффектом «живой печати» (текст печатается при нажатии любых клавиш игроком)
- Финальный экран с информацией об авторе проекта
