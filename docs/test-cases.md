# Тест-кейсы проекта «Один день на МКС»

Документ содержит ручные тест-кейсы для проверки основной функциональности интерактивной визуальной новеллы.

**Среда тестирования:** Google Chrome (последняя версия), разрешение 1920×1080  
**Тип тестирования:** ручное, функциональное, UI/UX  

---
